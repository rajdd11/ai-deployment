# Enterprise IT Troubleshooting Assistant

An AI-powered troubleshooting assistant built using Python and Google's Gemini API.

This project is part of my hands-on learning journey into Enterprise AI Engineering and Generative AI application development.

The assistant helps analyze IT-related issues and provides:
- Possible root causes
- Troubleshooting steps
- Severity assessment
- Escalation recommendations

---

# Features

- Interactive command-line interface
- Gemini 2.5 Flash integration after 
- Environment variable based API key management
- Structured troubleshooting responses
- Error handling
- Git/GitHub version control workflow

---

# Tech Stack

- Python 3.12
- Google GenAI SDK
- Gemini 2.5 Flash
- dotenv
- Git & GitHub
